# Label layer

The label layer is training-only. It may read future candles while constructing a target, but the target must never be merged into live feature inputs.

## Current target

For a candidate direction `d`:

```text
long adverse  = max(0, 1 - future_low / close)
short adverse = max(0, future_high / close - 1)
account risk  = leverage × (adverse × risk_penalty + 2 × fee)
```

The default horizon is 8 bars, and every row records `label_end`. Non-candidate rows receive missing labels and are excluded from training.

## Validation

- `label_end` is later than the decision timestamp.
- The final horizon rows remain unresolved.
- Long and short adverse movement uses mirrored formulas.
- Feature data never receives label columns.
- Truncated-history and full-history prefixes produce identical labels where the future horizon is available.
- Label changes require a new label version and model identifier.
