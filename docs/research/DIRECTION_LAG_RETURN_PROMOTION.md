# 方向准确率：滞后收益特征晋级

本轮唯一主指标是逐点方向准确率：`mean(sign(prediction) == sign(original_return))`。依据已有项目统计，未来 3 根收益与过去 1、2 根收益存在明显自相关；依据 Tashman (2000) 的 rolling-origin 评估原则，预先固定加入 `lag_return_1/2/3/6` 四列，不改变标签、模型参数、权重或早停。

实现位于 `quant/features/price.py`，四列在原始特征阶段生成，并由训练期 pipeline 一起拟合。契约测试确认每列只依赖当前及过去 close，前 `lag` 行为空，且未来行不会改变历史值。模型 identifier 更新为 `...-lagret-v1`，避免复用旧特征缓存。

两段历史窗口的逐点结果：

| 窗口 | 原模型 | lag 组 | 增量 |
|---|---:|---:|---:|
| 2026 rolling 六周 × 三币 | 397/756 = 52.51% | 406/756 = 53.70% | +1.19pp |
| 2023 H8 连续 252 点 × 三币 | 358/756 = 47.35% | 364/756 = 48.15% | +0.79pp |

2023 窗口的日期、truth、ready 均按 `(period, pair, UTC date)` 一对一核对，756/756 ready；连续 3 根日期块 bootstrap 增量区间为 `[-1.32pp, +3.04pp]`。两个窗口都属于已曝光历史开发数据，因此这是方向研究候选晋级，不宣称独立泛化确认。

按用户确定的晋级规则，方向准确率是唯一要求提升的指标；MAE、RMSE、Pearson、Spearman 不作为否决条件。生产模型需用新 identifier 重新训练，不能加载旧特征缓存。
