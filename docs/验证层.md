# Validation layer

The validation layer turns a wallet curve into a reproducible promotion report. It does not alter signals, positions, or execution assumptions.

## Metrics

`calculate_wallet_metrics()` calculates total return, annualized return, wallet Sharpe, wallet Calmar, maximum relative drawdown, and observation count from a timestamped wallet curve. The caller must set `periods_per_year` to match the wallet sampling interval; for an 8-hour curve use `365 × 3`, not `365`.

`calculate_deflated_sharpe_probability()` follows the selection-bias and non-normality correction described by Bailey and López de Prado.[31] `calculate_probability_of_backtest_overfitting()` implements the combinatorially symmetric cross-validation (CSCV) rank test described by Bailey, Borwein, López de Prado, and Zhu.[32]

## Promotion gates

`evaluate_promotion_gate()` fails closed when deflated Sharpe probability (DSR) or probability of backtest overfitting (PBO) is missing. When both are present, the candidate must satisfy all of the following:

- Maximum relative drawdown below 30%.
- Wallet Sharpe multiplied by wallet Calmar above the parent experiment.
- DSR at least 0.95.
- PBO at most 0.05.

The current implementation produces a `ValidationReport`; it does not claim a promotion until a full fee- and funding-aware portfolio backtest supplies the wallet curve and DSR/PBO values.

## Real execution-aware OOS result

The 15-pair OOS matrix used four pre-declared risk-penalty trials, non-overlapping 8-hour decisions, fixed 2x leverage, a 2% risk budget, fee and slippage assumptions, and local funding-rate files. The selected trial had DSR `0.4958` and PBO `0.6286`; the thresholds are DSR `≥0.95` and PBO `≤0.05`, so the candidate is rejected. Correctly annualized at `365 × 3` observations per year, the selected wallet returned `-5.88%`, Sharpe `-1.466`, Calmar `-1.270`, and maximum relative drawdown `8.54%`. The no-risk-penalty baseline had Sharpe × Calmar `1.872`, above the selected candidate's `1.861`.

## Smoke evidence

A synthetic timestamped wallet curve passed metric calculation, report validation, and both fail-closed missing-statistics and complete-statistics gate paths.
