这不是只通过 `git clone` 就能立即启动的模型包。复制模型后必须检查：

1. 目录名与 config 的 identifier 完全一致；
2. `pair_dictionary.json`、metadata 和模型文件齐全；
3. metadata 中的训练机绝对路径已改成远端 userdir；
4. 远端数据覆盖训练窗口和当前 1h bar；
5. 启动日志没有 `pretrained model`、`different features`、`FileNotFoundError` 或 `No common dates`。

模型目录不能提交 Git。小于 200 MiB 的模型包也只有在明确批准、带 manifest 和 SHA256SUMS 时才可进入仓库；当前 EXP184 模型不满足该交付范围。

## 启动门禁

启动前必须完成：

```bash
/home/wangke/project/freqtrade/.venv/bin/python -m py_compile \
  strategies/*.py strategies/freqaimodels/*.py

/home/wangke/project/freqtrade/.venv/bin/freqtrade list-strategies \
  --userdir /tmp/freqtrade-userdir \
  --strategy-path "$PWD/strategies"
```

然后执行短窗口真实 Freqtrade smoke，确认：

- 策略类加载为 `OK`；
- `XGBoostRegressorES` 可以解析；
- 预测缓存或模型可以读取；
- FreqAI 分析链路完成；
- 至少产生可解释的回测结果；
- 日志无 ERROR、Traceback、MergeError、Unable to analyze；
- 数据尾部足够新。

smoke 只证明运行链路，不代表长期收益晋级。收益晋级必须使用主窗口和独立早期窗口的同口径父子对照。
