# 部署说明

## 当前范围

本仓库只发布经过晋级的策略提交、脱敏配置和已验证的运行脚本。
API key、secret、私钥和远端密码不进入 Git。

## 部署前检查

```bash
git fetch origin
git switch main
git pull --ff-only origin main
git rev-parse HEAD
```

确认以下内容属于同一个晋级提交：

- 策略类。
- 配置文件。
- FreqAI identifier。
- 模型目录。
- timeframe、pairlist、杠杆和 stake。
- Freqtrade 版本或提交。

## 离线模型

完整且已批准的离线模型必须带：

- `manifest.yaml`
- `SHA256SUMS`
- 对应策略提交和 identifier
- 本地加载或部署冒烟结果

模型目录不能保留训练机绝对路径。
模型包总大小不超过 200 MiB 时可按仓库批准范围提交；运行缓存和未批准模型不得提交。

## 启动门禁

启动前必须完成：

```bash
python -m py_compile strategies/*.py
sha256sum -c SHA256SUMS
```

策略加载、模型加载、数据新鲜度和独立日志检查失败时停止启动。
