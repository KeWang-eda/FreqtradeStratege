保持的交易行为：4h、startup=100、单仓位、abs(模型输出) 排名、白名单稳定同分顺序、预测符号入场、无幅度阈值、原始换仓/退出理由、杠杆 min(2,max_leverage)、stoploss=-1、ROI=999、关闭 trailing。

明确的修正：

1. 独立特征函数不再因多次调用不同 period 覆盖列；FreqAI 适配仍输出原 schema，数值不变。
2. 未知技术指标和计算异常由 warning/跳过改成明确报错，符合 v2 要求；默认 features=[] 没有启用可选计算。
3. 入场信号也排除 NaN/Inf。旧代码 Inf 会生成单 pair 信号，但候选排名本来就排除 Inf；修正后两层规则一致。该异常输入差异有专门测试。
4. pct_change 明确不填缺失（当前 pandas 3 基线默认相同）。研究输入拒绝零价、无穷和乱序，兼容标签函数仍将零价标签处理为缺失。
5. 截断审计改为双向重叠比较，避免漏掉长窗口多出的交易；末端 force_exit 单独处理，不再声称“通过即证明无未来函数”。
6. 原 config.json 仅更新过时注释，实际交易/模型参数和 identifier 不变。

最终 holdout 默认封存。当前独立研究特征没有相关币对和 shifted-candle 展开，不能据研究指标直接替换生产 FreqAI 模型。LightGBM、风险策略、交易回测模型选择均未自动启用。
